# Detect-Lying-Sleeping-Person-Characteristics-using-HOG-Histogram-of-Oriented-Gradients-with-OpenCV

คำอธิบายสั้น ๆ

โปรเจกต์ใช้ HOG (Histogram of Oriented Gradients) ของ OpenCV เพื่อตรวจจับลักษณะของคนที่นอนหรืออยู่ในท่านอน จากภาพและวิดีโอ

ไฟล์หลักในโปรเจกต์

ไฟล์ / โฟลเดอร์คำอธิบายhog_test.pyสคริปต์หลักทดสอบการตรวจจับด้วย HOGimg/โฟลเดอร์เก็บภาพตัวอย่างภาพ .jpg หลายไฟล์ภาพตัวอย่างคนนอนบนเสื่อสีฟ้าipcam3.mp4วิดีโอทดสอบจากกล้อง IP Camera

เทคโนโลยีที่ใช้

Python

OpenCV (HOGDescriptor + SVM People Detector)

ภาพและวิดีโอสำหรับทดสอบ

หลักการทำงาน

ใช้ cv2.HOGDescriptor() พร้อม HOGDescriptor_getDefaultPeopleDetector()

ตรวจจับคนในภาพ/วิดีโอด้วย detectMultiScale

เน้นตรวจจับในท่านอนหรือท่านอนราบ (lying posture)
